# БЫТОВОЙ — мобильный интернет-магазин

Готовый адаптивный мобильный сайт по предоставленному макету.

## Запуск
Откройте `index.html` в браузере или запустите локальный сервер из этой папки:

```bash
python -m http.server 8000
```

Затем перейдите на http://localhost:8000.

## Что работает
- Главная страница с промо-баннером, категориями и популярными товарами
- Каталог с поиском и переключением категорий
- Карточка товара
- Добавление в корзину, изменение количества и удаление
- Избранное
- Мобильная нижняя навигация и фильтр-модалка

Изображения товаров и кухни вырезаны из предоставленного референс-макета.
